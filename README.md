# 🕯️ Birthday Candle Age Finder

> A vibecoding-champion single-page widget that calculates birthday candle needs with glassmorphism UI, animated flames, and celebratory delight.

## 🔗 Live Demo

**[→ Open Live Demo](https://rizkiramadhani561.github.io/birthday-candle-age-finder/)**

## ✨ Features

- **Live Age Calculator** — Enter birth year (YYYY or YY shorthand) or switch to direct age input
- **Taper Candle Count** — Exact number of individual candles needed
- **Numeral Candle Breakdown** — Smart digit-splitting (e.g. 42 → "4" + "2")
- **Animated CSS Candle Flames** — Click candles to light them up 🔥
- **AI-Powered Birthday Messages** — Randomized heartfelt / humorous / inspirational messages
- **Milestone Easter Eggs** — Special messages for ages 1, 13, 18, 21, 30, 50, 100, and more
- **Lucky Number Badges** — Special callouts for 77, 88, 99, 123
- **Confetti Particle Burst** — Pure CSS particles on every calculation
- **Dark / Light Mode Toggle** — Cozy dark glassmorphism with gold accents
- **Copy Shopping List** — One-click copy of your full candle order
- **Share Birthday** — Web Share API with clipboard fallback
- **Dynamic Warm Background** — Gradient shifts based on age
- **LocalStorage Memory** — Remembers your last calculation on next visit
- **Offline Ready** — Zero external dependencies

## 🎨 Design

- **Glassmorphism** with `backdrop-filter: blur(20px)`, warm amber/orange palette
- **Mobile-first**, fully responsive
- **WCAG AA accessible** — semantic HTML, ARIA labels, keyboard navigation, 4.5:1+ contrast
- **< 25KB total** — single HTML file, no frameworks, no CDN calls

## 🚀 Usage

```bash
git clone https://github.com/RizkiRamadhani561/birthday-candle-age-finder.git
open index.html
```

## 🏗️ Tech Stack

- Vanilla HTML5 + CSS3 + ES6 JavaScript — no frameworks, no build step
- CSS `@keyframes` for all animations
- Web Share API + Clipboard API + LocalStorage
